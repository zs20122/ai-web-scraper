## 项目简介

传统 `requests` 只能拿到静态 HTML，遇到 JS 渲染、无限滚动、懒加载的页面就会漏数据。本工具用 Playwright 驱动真实 Chromium 内核，等页面「彻底渲染」后再取完整 HTML；再让 DeepSeek 大模型按你的一句话需求，把页面内容提取成结构化 JSON，渲染成整齐表格，一键导出 CSV。

一句话描述：**「给我 URL 和需求，还你一张干净的数据表。」**

## 核心亮点

### 🎭 Playwright 动态渲染

用真实 Chromium 内核执行页面 JS，完整还原 SPA、异步加载、Ajax 渲染的内容——`requests` 抓不到的数据，这里都能拿到。

### 📜 无限滚动机制

`_scroll_to_load_all` 反复滚到底部，监测 `scrollHeight` 是否继续增长，直到页面高度稳定才取 HTML，自动触发「下拉加载 / 无限滚动」类页面的懒加载。

### 🧠 LLM 语义提取

不用写 XPath 或 CSS 解析规则，用一句话描述需求（如「提取每部电影的名字、链接和评分」），DeepSeek 即返回结构化 JSON。系统提示词内置严格 Schema 约束 + 键名归一化，多页合并后列名稳定不乱。

### ✂️ CSS 预过滤降本

大模型按 token 计费，页面 HTML 越大越贵。可指定 CSS 选择器（如 `ol.grid_view`），只把命中的目标节点发给大模型，既避免上下文截断，又显著降低 token 开销。

### 🛡️ 健壮性与防反爬

针对真实抓取中的反爬与异常做了专门加固：导航 / 执行上下文被销毁时自动等待并重试；页间随机 3–6 秒拟人化停顿；隐藏自动化特征（`AutomationControlled`）；支持加载登录态 `storage_state.json` 应对需登录站点；单页失败自动跳过并记录日志，绝不中断整批任务。

## 功能特性

- **真实浏览器渲染**：Playwright 驱动 Chromium，完整执行 JS。
- **无限滚动支持**：自动滚到底部触发懒加载，直到页面高度不再增长。
- **智能语义提取**：接入 DeepSeek，自然语言需求 → 结构化 JSON。
- **分页爬取**：自动识别页码式（`page`/`p`/`pn`/`pagenum`）与偏移式（`start`/`offset`，默认步长 25）。
- **跨页去重**：以「链接」为唯一键去重合并，杜绝翻页失效导致的数据重复。
- **防反爬**：页间随机休眠、隐藏自动化特征、支持加载登录态（storage_state）。
- **异常容错**：单页失败自动跳过并记录日志，不中断整体任务。
- **CSV 导出**：一键导出（UTF-8 BOM，Excel 打开中文不乱码）。

## 实战验证

| 场景 | 目标 | 结果 |
| --- | --- | --- |
| 偏移量分页 | 豆瓣电影 Top250 × 3 页 | 75 条、零重复（名字 / 链接 / 评分） |
| 无限滚动 | 网易新闻首页 | 滚动后条目 `li` 443 → 999 |
| 多页合并去重 | SegmentFault 问答 × 2 页 | 合并 14 条无重复 |

> 曾修复的关键问题：豆瓣 `start` 偏移量分页失效（页页都是第一页）、多页键名语言不统一导致列错位、翻页时被风控强制重定向崩溃——现已用「自动重试 + 拟人化延时 + 登录态」三重防护解决。

## 快速开始

### 1. 环境要求

- Python 3.9+
- 一个可用的 [DeepSeek API Key](https://platform.deepseek.com/)

### 2. 安装依赖

```bash
python -m venv venv

# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate

pip install -r requirements.txt
```

### 3. 安装浏览器内核

Playwright 的 Python 包不包含浏览器，需额外下载：

```bash
playwright install chromium
```

### 4. 配置 API Key

复制 `.env.example` 为 `.env`，填入你的 Key：

```bash
cp .env.example .env   # Windows 可手动复制改名
```

`.env` 内容：

```ini
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
```

> ⚠️ `.env` 已加入 `.gitignore`，不会被提交，请勿泄露 Key。

### 5. 启动

```bash
python app.py
```

浏览器访问 <http://127.0.0.1:5000/>。

## 使用指南

### 表单字段

| 字段 | 说明 |
| --- | --- |
| 目标网页 URL | 要抓取的页面地址 |
| 数据提取需求 | 可选。自然语言描述要提取什么，如「提取所有文章标题和链接」 |
| CSS 选择器 | 可选。只把命中的节点发给大模型，如 `ol.grid_view` |
| 最大抓取页数 | 分页爬取用，默认 1 页 |

### 单页抓取

只填 URL，点击「开始抓取」，页面下方展示去除 script/style 后的清理 HTML。

### 智能提取

填 URL + 需求，大模型返回 JSON 数组，渲染成表格，可一键导出 CSV。

### 分页爬取

填 URL + 需求 + 页数 N。工具会识别分页规律、依次抓取第 1…N 页、按「链接」去重合并成一张大表；某页失败时跳过并记录日志。

## 关键默认值

| 配置 | 值 | 位置 |
| --- | --- | --- |
| 页面加载超时 | 30 秒 | `fetch_html` |
| 网络空闲等待 | 15 秒 | `fetch_html` |
| 页间防反爬延时 | 随机 3–6 秒 | `index()` |
| 大模型上下文截断 | 50000 字符 | `MAX_HTML_CHARS` |
| 大模型 | `deepseek-chat` | `DEEPSEEK_MODEL` |
| 固定输出列 | 名字 / 链接 / 评分 | `SCHEMA_KEYS` |
| 偏移分页步长 | 25 | `OFFSET_PAGE_SIZE` |

## 注意事项

- 多页抓取时请求会持续较久（页间有 3–6 秒拟人化延时），属正常现象。
- 分页识别支持页码式与偏移式；路径式（`/page/2/`）需自行扩展 `paginate_url`。
- 遇到需要登录的站点：运行 `python save_storage_state.py <目标URL>` 导出登录态，`fetch_html` 会自动加载 `storage_state.json`。
- 请遵守目标网站的服务条款与 robots 协议，合理控制抓取频率。
